# 世界书灯 LoreLamp

一个基于 SillyTavern 的第三方前端插件（扩展）。它把 **世界书（World Info / Lorebook）** 的
“蓝灯 / 绿灯”识别、开启/关闭、楼层提炼、以及 **临时 / 永久** 写入整合到一个悬浮面板里。

> 术语说明（沿用你们 tavern-cards 体系）：
> - **蓝灯 = 恒定 / 常驻条目**（constant）：一直在上下文里，无需关键词触发。
> - **绿灯 = 关键词触发条目**（selective）：命中 `key` 才注入上下文。

---

## 功能

1. **拉取世界书 + 识别蓝灯/绿灯 + 开关**
   - 下拉选择任意一本世界书，列表逐条显示 **蓝灯 / 绿灯 / 向量 / 关闭** 状态（彩色圆点 + 开关拨杆）。
   - 随时开关某条目（写入 `disable` 字段并保存）。
   - 面板顶部同时显示当前聊天的临时库及其蓝灯/绿灯计数。

2. **选取历史楼层、提炼、按方向写入世界书**
   - 楼层区间自由选取：单个楼层（如 `12`）或区间（如 `3-20`，含端点，可填负数表示倒数）。
   - 提炼方向二选一：**人物** / **世界观**。
     - 人物 → 生成**绿灯**条目，用角色名/别名做触发关键词。
     - 世界观 → 生成**蓝灯**常驻条目。
   - 调用酒馆当前所配置的后端做一次**静默生成**（quiet generation，不污染聊天记录），
     解析模型返回的 JSON，在面板里预览每条拟写入的设定（可勾选）。
   - 确认后写入世界书。

3. **临时写入 vs 永久写入**
   - **临时（仅当前聊天）**：写入当前聊天的**聊天级世界书**（chat lorebook，绑定在
     `chat_metadata` 上）。开启新的聊天即不会继承，符合“新聊天清空”。
   - **永久（跨聊天）**：写入一本**绑定在当前角色卡上的附加世界书**（默认名 `提炼库_<角色名>`，
     名称可在面板修改）。只要还是这张卡，任意新聊天都会加载这本库，设定长期保留。
     永久库写入后会绑定到角色卡的 `world_info.charLore`，随角色卡一起保留。

## 部署

把构建产物放进酒馆的第三方扩展目录：

```
SillyTavern/public/scripts/extensions/third-party/
└── tavern-lorelamp/
    ├── manifest.json
    └── dist/
        ├── index.js
        ├── index.css
        └── index.js.map
```

即把本项目整目录放到上面的 `third-party/` 下（或按酒馆习惯做符号链接），然后**刷新酒馆网页**。
加载后画面**右下角会有一颗可拖动的悬浮球 📖**：

- **单击悬浮球**：打开/收起工具箱面板。
- **拖动悬浮球**：把它移到任意位置（记忆到本地，刷新后仍在原位）。
- **点悬浮球上的小「＋」**：弹出快捷菜单——
  - `📖 打开面板`
  - `⚡ 提炼最近20层·人物`
  - `⚡ 提炼最近20层·世界观`（一键提炼最近 20 层并弹出预览，勾选后写入）

> 要求：SillyTavern `>= 1.12`（与酒馆助手 JS-Slash-Runner 同版本线）。
> 构建产物内已经写好相对酒馆 `public/` 根的相对引入（5 级），放到标准目录即可用，无需再次构建。

## 自行构建（可选）

需要 Node 22+：

```bash
npm install
npm install-scripts approve esbuild   # 首次安装让 esbuild 二进制生效
ST_IMPORT_DEPTH=5 npm run build       # dist/ 下的 index.js 会按 5 级路径引用酒馆模块
npm run watch                         # 开发时增量构建，刷新增量即可生效
```

> 说明：因为本仓库不在酒馆的 `public/` 目录树内构建，所以用 `ST_IMPORT_DEPTH=5` 指定
> 由 `dist/` 回到 `public/` 根的相对层级（标准第三方扩展路径为 5 层）。

## 说明与限制

- 提炼依赖酒馆当前配置的后端可用，且需联网生成；生成失败会给出提示，不会误写入。
- “临时（仅当前聊天）”本质是聊天世界书：开**新聊天**自动清空；但若你**恢复**旧聊天文件，
  旧聊天里写入的临时条目仍在（那是酒馆聊天级世界书的既定行为）。
- 永久库绑定到角色卡。如果当前没有打开角色卡，永久写入只会创建库但暂不绑定（提示以 toast 为准）。
- 提取提示词要求模型返回 JSON 数组；解析做了容错（剥 ```` ``` ```` 围栏、取首个数组）。
